# ya-workspace-sidebar Agent Guide

- Bundle patch disables official `ui-workspace`; this plugin must continue to provide both `sidebar.workspaces` and `conversation.hero.workspace`.
- Since DSH v0.1.2-alpha.1 the official ui-sidebar/ui-conversation/ui-agent-preset and directory-picker client entries inject the `uiWorkspace` service; this plugin's client entry provides the stand-in (`src/client/navigation.ts`) carrying the reuse-or-create, current/recent fallback, archived-current clearing, and boot auto-selection semantics. Removing it re-creates the WebUI boot deadlock.
- `dsh/` is read-only. Do not patch official client packages.
- Recent Sessions is global, newest-first, virtual-scrolled (fixed 35px row stride, bounded scroll viewport, shows the full recency list rather than five rows), and hidden during search.
- A draggable (and arrow-key adjustable, double-click resettable) separator between Recent Sessions and the workspace browser sets the recent viewport height; the preference persists per-browser in `localStorage` and clamps so the workspace area keeps a minimum.
- Root navigation lists real workspaces plus virtual Ungrouped, grouped by local calendar date of last session activity (Ungrouped participates; undated rows trail without a header); each row shows relative last-used time instead of session count. Level two lists only the selected workspace's sessions.
- Workspace rows carry no hover buttons; right-click opens a cursor-anchored menu (new session / reveal in explorer / copy path / rename / delete, real workspaces only) mounted only while open. Row titles truncate with a `mask-image` fade instead of an ellipsis; the path keeps a plain left-aligned ellipsis clip.
- Manual breadcrumb back remains at root until the current session id changes.
- Row titles are the durable `summary.title` only (blank → localized New Session, missing/whitespace → localized Untitled). Never use `summary.displayTitle`: its cwd-basename fallback renders every cold session as the workspace folder name until the session is opened once. Untitled rows self-heal: `WorkspaceSidebar` calls `ctx.sessions.refreshProjections(id)` once per session per mount (host folds the log → exact 'sequenced' title, no session open).
- Host `src/index.ts` maintains the cold-title pipeline on top of the per-record `session_projcache` domain (spec v7, `<storages>/session_projcache/sessions/<id>.json`): on `session/title` it retries the official `cache.write(session)` (the mid-turn checkpoint can throw non-JSON-serializable values) and merges a title-only row on failure; a boot backfill (`sessionPersistence.list()` → `sessionQuery.observeSession`) merges titles the cache cannot serve. The old single-file `storages/session_projcache.json` layout is dead — never write it.
- Real workspace level groups sessions by local calendar date (newest date first, `updatedAt` descending within a group); drag-to-reorder is disabled. Pinned rows (browser-local flag) lift above the date groups into a leading Pinned section; search results ignore pinning.
- Session rows open one shared context menu (right-click and the … button): pin/unread are browser-local `localStorage` flags (`src/client/session-flags.ts`, never Host state); unread renders a blue status dot with priority below pending-interaction/running and clears on open; the task/log path actions probe the jsonl storage layout through this plugin's fenced host routes (`/ya-workspace-sidebar/paths|reveal`, mounted via runtime `ctx.inject(['webServer'])` so the title-cache listener survives webServer-less profiles) and stay disabled on sqlite-backed deployments.
- Build artifacts in `lib/` are prebuilt and must remain publishable.
